A full-stack store rating platform built as part of a technical assessment.

The application supports role-based functionality for **Admins, Normal Users, and Store Owners**, allowing users to rate stores while administrators manage users and stores.

## ✨ Highlights

- JWT-based authentication
- Role-Based Access Control (RBAC)
- Three user roles: Admin, Normal User, and Store Owner
- Store rating and rating modification
- Admin management of users and stores
- Store Owner rating dashboard
- Search, filtering, sorting, and pagination
- PostgreSQL relational database with raw SQL

## 🛠 Tech Stack

- **Frontend:** React + Vite
- **Backend:** Node.js + Express.js
- **Database:** PostgreSQL
- **Authentication:** JWT
- **Password Hashing:** bcryptjs
- **Database Driver:** node-postgres (`pg`)
